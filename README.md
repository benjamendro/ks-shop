# הסל הזול — קריית שמונה

אפליקציית רשת (PWA) להשוואת מחירי סופרים בקריית שמונה. בונים רשימת קניות עם כמויות, והאפליקציה מחשבת את סכום הסל בכל סניף, איפה הכי זול, מה חסר, סכום הפריטים המשותפים, ומה השילוב הזול ביותר אם מפצלים את הקנייה.

הרשימה נשמרת במכשיר (localStorage) ושורדת רענון. אפשר להתקין במסך הבית ולהשתמש גם בלי קליטה, עם הקטלוג שכבר נשמר.

האפליקציה בנויה משלושה מסכים עיקריים: קטלוג (חיפוש, מחלקות והוספה בלחיצה), רשימת הקניות (כמויות, פינוי והערכת מחיר), והשוואת הסל (דירוג סניפים, טבלת מחירים לפי פריט, ופיצול מעשי בין שתי חנויות אם זה חוסך). בחיפוש אפשר למיין לפי מחיר או מחיר ליחידה, והמוצרים מקובצים לפי יצרן עם המחיר בכל סופר על אותו כרטיס.

## מקור הנתונים

המחירים מגיעים מ־[Over.org.il (גרסאות לעם)](https://www.over.org.il) — API ציבורי בלי מפתח, שאוסף את קובצי שקיפות המחירים שהרשתות מחויבות לפרסם לפי חוק קידום התחרות בענף המזון.

המחירים הם **מחירי מדף**. מבצעים מוצגים כתגית ליד המוצר. מבצע מועדון, קופון או תנאי מיוחד לא מקוזז אוטומטית. אפשר להפעיל «חשב מבצעים פשוטים» רק למבצעי כמות עם מחיר יעד, בלי מועדון ובלי קופון.

## סלים מוכרים

עמוד `#/baskets` משווה שלושה סלי מדד מוכרים מול מחירי הסניפים בקריית שמונה, ומחשב אותם מחדש בכל רענון יומי מתוך `web/data/baskets.json` והקטלוג העדכני:

1. **הסל של ישראל** — 100 מוצרי יסוד עם ברקודים, משרד הכלכלה והתעשייה (ינואר 2026).
2. **מוצרי פיקוח** — מצרכי היסוד שבפיקוח מחירים (משרד הכלכלה ומשרד החקלאות).
3. **סל יומיומי ארצי** — מדד 65 המוצרים הקבועים של WizStore (רשימה ציבורית; אינו סל ממשלתי).

ההתאמה בין הרשתות היא לפי **ברקוד** (8–14 ספרות). קודים פנימיים קצרים לא מאוחדים בין רשתות, כדי למנוע התנגשויות.

## קטגוריות

לקובצי החוק ול־Over אין שדה קטגוריה. הסיווג נעשה לפי עץ המחלקות של הרשתות הגדולות (שופרסל / רמי לוי) וחוקי מילות מפתח בעברית, עם עדיפות לביטויים ספציפיים ועם דריסה לקטגוריית «קפואים» כשמופיעה המילה «קפוא». מוצרים שמופיעים רק בפארם ולא סווגו לפי השם, מועברים למחלקת הפארם. שאר המוצרים שלא זוהו מופיעים תחת «אחר» ועדיין ניתנים לחיפוש.

נכון לקטלוג של 13.11.2026: 37,033 מוצרים, כ־84% שויכו למחלקה, והשאר ב«אחר».

## רענון יומי

```bash
python scripts/build_catalog.py
```

מושך את כל מחירי הסניפים מ־Over ובונה מחדש את `web/data/`. קובץ `.github/workflows/refresh.yml` מריץ את זה כל בוקר (07:30 לפי שעון ישראל / Asia/Amman) ודוחף את הנתונים, אחרי שהמאגר מפורסם ב-GitHub.

## הרצה מקומית

```bash
./scripts/serve.sh          # http://127.0.0.1:8765/
```
